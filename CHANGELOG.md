# Changelog

All notable changes to the community health files and the repository standard are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Changed

- Social preview: the standard now requires the GitHub default preview and forbids uploading a
  custom image.
- Changelog: WordPress.org plugins may keep `readme.txt` and `changelog.txt` as the changelog of
  record, with `CHANGELOG.md` optional.

### Added

- Repository hygiene files, issue forms, pull request template, Dependabot configuration and a
  Markdown lint workflow for this repository.

## [1.0.0] - 2026-10-31

### Added

- Default community health files: `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`,
  `SUPPORT.md` and `FUNDING.yml`.
- `STANDARDS.md`, the repository contract for structure, documentation, metadata, CI, releases and
  GitHub settings.
