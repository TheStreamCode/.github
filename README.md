# Default community health files

This repository provides the default community health files for repositories owned by
[TheStreamCode](https://github.com/TheStreamCode) that do not ship their own copy:
`CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md` and `FUNDING.yml`.

It also documents the [repository standard](STANDARDS.md) used for every public project: structure,
documentation, metadata, CI, release process and GitHub settings.
